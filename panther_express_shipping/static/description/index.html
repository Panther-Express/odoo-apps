Panther Express Shipping

Create your shipments without leaving Odoo

Connects Odoo eCommerce, Sales and Inventory with the Panther Express shipping API: one click on the Sales Order creates the waybill, and the delivery status comes back to Odoo automatically. No copy-paste into a courier portal, no spreadsheets, no double entry.

Create a shipment in one click

A Create Panther Shipment button on the Sales Order and on the Delivery Order calls addBulkShipments and stores the waybill, the Panther id and the QR code. The waybill is copied to the Delivery Order tracking reference.

Live tracking

The Tracking screen shows every waybill with its customer and its current status. Refresh Status calls getCurrentStatus, and the public webhook /panther/webhook/status lets Panther push each update to Odoo in real time.

A real delivery method

Panther Express is a native Odoo delivery carrier: the customer picks it on the eCommerce checkout, the shipping cost is computed from a fixed price plus an optional price per kilo, and Send to Shipper works as with any other carrier.

Configuration in one page

API credentials, sender name / phone / address / sector, default sector, service type and webhook token live in Panther Express > Configuration > Settings (stored in ir.config_parameter), with a Test Connection button.

How it works

  1. The customer checks out on your website and picks Panther Express as the delivery method.
  2. You confirm the Sales Order and press Create Panther Shipment (or use Send to Shipper on the Delivery Order).
  3. Odoo calls the Panther API, receives the waybill, and writes it on the shipment, the order and the delivery.
  4. Panther pushes each status change to /panther/webhook/status, or you press Refresh Status to pull it.

Setup

Install the module, then open Panther Express > Configuration > Settings and fill in the API URL, your Panther username and password, and your pickup (sender) details. Press Test Connection to confirm, and you are ready to ship. Contact Panther Express to get your API credentials and your sector id.

Requires: Odoo 17.0 — Sales, Inventory, Delivery and Website (eCommerce). All of them ship with Odoo Community.
